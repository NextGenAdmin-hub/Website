# Quick Start Guide

## Installation Steps

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Run Development Server**
   ```bash
   npm run dev
   ```

3. **Open Browser**
   Navigate to: http://localhost:3000

## What's Included

✅ **5 Complete Pages:**
- Home (`/`)
- About (`/about`)
- Services (`/services`)
- Testimonial (`/testimonial`)
- Contact Us (`/contactus`)

✅ **Modern Features:**
- Animated NGW/NextGen logo
- Glassmorphism effects
- Smooth scroll animations
- Responsive navigation
- Gradient backgrounds
- Interactive forms

✅ **Tech Stack:**
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion

## Customization Tips

1. **Update Logo Colors**: Edit `components/Logo.tsx`
2. **Change Brand Colors**: Modify `tailwind.config.js`
3. **Update Content**: Edit page files in `app/` directory
4. **Modify Animations**: Adjust Framer Motion props in components
